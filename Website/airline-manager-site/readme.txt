=== Airline Manager Pro Website ===
Requires Plugins: elementor
Requires at least: 6.0
Requires PHP: 7.4
License: GPL-2.0-or-later

The Airline Manager Pro website for Elementor: a showcase home page with a live route map, a carousel
with a screenshot of every part of the app, the app on Android and Windows, downloads that follow the
newest release, questions, and a page with the full feature list.

== Install ==
1. Install and activate the free Elementor plugin.
2. Plugins → Add New → Upload Plugin → airline-manager-site.zip → Install → Activate.
3. Two pages are created and the home page becomes the site's front page (only if the site was still
   showing the latest posts there). See Settings → Airline Manager Pro website.

== Updates ==
* The newest plugin is always on the GitHub release "airline-manager-website". Upload it the same way
  (WordPress asks whether to replace the installed version: choose Replace).
* The feature page and the app screenshots are updated by GitHub whenever the app changes.
* The download buttons and the version number follow the newest app release by themselves.

== Editing ==
* Open a page with "Edit with Elementor". Every section is an Airline Manager widget (left panel,
  category "Airline Manager Pro"): click it to change its texts, screenshots and links.
* The carousel: Hero widget → the three first screenshots and "More screenshots".
* Social links, fixed download links, a Google Play link and the copyright name:
  Settings → Airline Manager Pro website.
* The copyright year updates by itself ([airline_manager_year] shortcode, also usable anywhere).
