**Airline Manager Pro 0.5.4: what's new, in the app**

- **AirlineManagerPro-0.5.4.apk**, the phone app. It installs over 0.5.3 and keeps your airline.
- **AirlineManagerPro-PC-0.5.4.zip**, the PC app with the Windows app inside. Update it too, so the Windows app shows what's new as well.

**What's new**
- After every update the app shows what's new: the newest version's changes, new features and fixes, open at the top, and the two versions before it folded underneath. Tap one to open it.
- Fold the newest one away if you don't need it. It opens again by itself when the next update arrives.
- Open it again at any time from Settings → General → What's new.
