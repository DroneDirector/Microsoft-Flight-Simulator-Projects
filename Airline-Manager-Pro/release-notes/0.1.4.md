**Airline Manager Pro 0.1.4**

**One-time step:** uninstall the old Airline Manager Pro before installing this version. From now on every new version installs straight over the previous one.

- Your airline is now **saved on the phone** and kept through every update and restart.
- **Map layer button** on the world map (Overview and full screen): Street map or Satellite, tap again for the classic map.
- Settings → About → **Start over** deletes the saved airline if you want a fresh start.
