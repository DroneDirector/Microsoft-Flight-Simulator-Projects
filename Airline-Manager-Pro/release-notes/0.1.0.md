**Airline Manager Pro 0.1.0, first preview**

Every screen is in its real place with final-style graphics and animations, running on demo data so the look and feel can be tried before the simulator link is built.

Try: the Overview widgets, the live map, buying an aircraft (with sound), the mechanic's message in the inbox, the crash decision in Flight logs, switching company from the top-left, and Settings → ATC.

Next: the PC bridge that links the app to Microsoft Flight Simulator 2024 over Wi-Fi and mobile data.
