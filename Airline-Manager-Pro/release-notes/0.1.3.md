**Airline Manager Pro 0.1.3**

- **Layer button** on the world map (Overview and full screen): pick **Street map** or **Satellite**. Tap the button again to go back to the classic map.
- **Street map** uses OpenStreetMap with familiar light colours.
- **Satellite** uses Sentinel-2 cloudless imagery, much sharper than before.
- Both need an internet connection. The classic map works offline.
