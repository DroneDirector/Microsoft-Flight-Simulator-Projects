**Airline Manager Pro 0.3.1: error log and updates from inside the app**

Two downloads:
- **AirlineManagerPro-0.3.1.apk**, the phone app.
- **AirlineManagerPro-PC-0.3.1.zip**, the PC app for the Windows PC with Flight Simulator.

**If Android says "App not installed"**
Android shows that message itself, before the app runs. It usually means an older test copy (0.1.3 or earlier, signed with a different key) is still installed, or Google Play Protect blocked it. Uninstall Airline Manager Pro once and install this APK. From 0.3.1 on, updates install from inside the app, and if Android refuses, the app shows Android's exact reason.

**New**
- Error log: when something goes wrong, a pop-up shows the error with Copy and Share. Every error is also saved in Settings → Updates and errors.
- If the app can't start at all, it shows the error with Copy and Share instead of a blank screen. A crash in the Android part is reported on the next start.
- Updates: the app checks for new versions, downloads them and hands them to Android's installer (Settings → Updates and errors → Check for updates). Android asks once for permission to install from the app. Your airline is kept.
- PC app: everything it shows is also saved in `%APPDATA%\Airline Manager Pro\pc-app.log`. If it stops on an error, the window stays open with the details.
