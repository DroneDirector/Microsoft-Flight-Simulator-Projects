# Replaceable sounds

Put a sound file with one of these names in this folder (`.ogg`, `.mp3`, `.wav` or `.m4a`) and build the app: the game
plays it instead of making that sound itself. Remove it and the game's own sound comes back. This list is written by
the build. Short, clean recordings work best; the game sets their volume (footsteps by how fast you walk).
Licences of sounds you use must allow commercial sale (CC0 is simplest).

| File | Sound |
|---|---|
| `footsteps-carpet.ogg` | A footstep on carpet (offices, the lounge, the cabin aisle) |
| `footsteps-wood.ogg` | A footstep on a wooden floor (your office) |
| `footsteps-tile.ogg` | A footstep on tiles or stone (the concourse, the galleys) |
| `footsteps-concrete.ogg` | A footstep on concrete (the hangars, the apron) |
| `footsteps-metal.ogg` | A footstep on metal (steps, gratings) |
| `door-wood-open.ogg` | A wooden door opening (your office, Operations) |
| `door-wood-close.ogg` | A wooden door shutting |
| `door-metal-open.ogg` | A metal door opening (the hangars' rooms, the staff door) |
| `door-metal-close.ogg` | A metal door shutting |
| `door-glass-open.ogg` | A glass door opening |
| `door-glass-close.ogg` | A glass door shutting |
| `door-sliding-open.ogg` | Sliding doors opening (the lounge, the concourse) |
| `door-sliding-close.ogg` | Sliding doors shutting |
| `door-knock.ogg` | A knock at your office door |
| `vending-button.ogg` | The vending machine's keypad beep |
| `vending-coil.ogg` | The vending machine's motor turning a coil |
| `vending-drop.ogg` | An item dropping into the vending machine's tray |
| `vending-flap.ogg` | The vending machine's flap |
| `can-open.ogg` | Opening a can |
| `snack-bite.ogg` | A bite of a snack bar |
| `drink-sip.ogg` | A sip from a can or a cup |
| `put-down.ogg` | Putting something down on a table |
| `coffee-touch.ogg` | A tap on the coffee machine's touchscreen |
| `coffee-grind.ogg` | The coffee machine grinding beans |
| `coffee-pour.ogg` | Coffee running into the cup |
| `coffee-milk.ogg` | The coffee machine frothing milk |
| `coffee-water.ogg` | Hot water running (tea, americano) |
| `cup-down.ogg` | A cup set down on its saucer |
