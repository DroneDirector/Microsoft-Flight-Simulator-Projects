HELICOPTERS
Reference guide | Prepared 3 November 2026

For every helicopter in Airline Manager Pro: what it is used for, seats, crew, weights, speeds, range, dimensions,
engines and weather limits. Broad, approximate educational figures for the app's simulation, not operational data.
Never use this guide to operate an aircraft. (C) after a section = some figures in it worked out, not published.
